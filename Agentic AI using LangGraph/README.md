## How to use

Choose a video folder, then open its PDF or DOCX. You can click chapter timestamps in those files to jump directly into the lesson on YouTube. Open `.md` alongside its adjacent `images/` folder; upload the whole folder to GitHub to keep diagrams visible. Original diagrams help explain code concepts. Exercises and runnable no-API-key examples are included where practical.
