## How to use

Start with video 3 for the framework comparison, then video 4 for the core concepts before studying the four workflow patterns. Chapter timestamps link directly to the corresponding lesson on YouTube. Exercises and runnable no-API-key examples are included where practical.

When reading on GitHub, keep Markdown files alongside their image folders so diagrams remain visible.
